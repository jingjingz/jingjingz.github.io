LASSO vs. ridge regression

Same least-squares problem. Different penalties. Move the slider to see how the estimated coefficients change.

Where do the shapes come from?

Each point in the (β1, β2) plane is a different regression model. The height of a function at that point is its loss or penalty. A contour connects points with the same height, like a contour line on a topographic map.

1. Data-fitting term: ellipses

L(β) = (1/2n) ∑i(yi − xiTβ)2

Same ellipse = same training loss. OLS is at the center, where the loss is smallest. Moving away raises the squared prediction errors. Correlation between predictors tilts the ellipses.

2. Ridge penalty: circles

β12 + β22 = 4  ⇔  ||β||2 = 2

Same circle = same squared Euclidean distance from zero. (2, 0) and (√2, √2) both have squared norm 4. Large coefficients become increasingly expensive.

3. LASSO penalty: diamonds

|β1| + |β2| = 2

Same diamond = same sum of absolute magnitudes. (2, 0) and (1, 1) both cost 2. In each quadrant, the boundary is a straight line; the axes form sharp corners.

Putting the terms together: the loss pulls the estimate toward OLS; the penalty pulls it toward the origin. Multiplying a penalty by λ changes its weight, not the shape of its level sets. The penalized optimum is also the lowest-loss point inside a corresponding penalty budget (the shaded region below). The budget depends on the chosen λ and differs between methods. A diamond corner can force one coefficient to zero, while a smooth circle usually cannot.

Why does LASSO select variables?

Each gray ellipse is a level set of the least-squares loss. The fitted point minimizes loss within the colored feasible region. The diamond has corners on the coordinate axes, so the first contact can occur at a coefficient of exactly zero. The circle is smooth, so ridge generally retains all predictors while shrinking the coefficient vector.

Both methods trade a higher training error for regularization, which can reduce prediction variance. Choose λ using validation data or cross-validation, and standardize predictors before fitting.

Model and scaling used in this demo

Two centered, standardized predictors have correlation ρ = 0.4, with OLS coefficients (2.0, 0.9). The intercept is unpenalized. We use L(β) = RSS(β)/(2n), up to an additive constant. The corresponding quadratic loss is ½[(β₁−2)² + 2ρ(β₁−2)(β₂−0.9) + (β₂−0.9)²].

All estimates are computed from this same fixed quadratic problem. The ridge circle has radius ||β̂ridge||2, and the LASSO diamond has radius ||β̂lasso||1, giving the constrained equivalent of each penalized solution. Equal values of λ need not imply equal effective shrinkage between penalties. This example does not simulate test error.

What to look for

OLS: minimizes training error. With limited data and correlated predictors, the estimated coefficients can be unstable and test error can be high.

Ridge: shrinks coefficients and can distribute the signal among correlated predictors. It is often useful when many predictors have small effects.

LASSO: shrinks and can set coefficients exactly to zero. It is often useful when a sparse predictive model is plausible. Correlated predictors can make selection unstable.

Try: change the signal to dense, increase the sample size, or generate a new dataset. No method is guaranteed to win for every realization.

From this demo to real data

Standardize predictors using training-set means and standard deviations only, fit the intercept without a penalty, and tune λ by cross-validation. Keep a final test set untouched until model selection is complete. LASSO's selected variables are predictive associations, not necessarily causal effects or stable discoveries.

Simulation and fitting details

All features have population variance 1. Independent blocks of five jointly Gaussian features have equicorrelation 0.55. The response is y = 1 + Xβ + ε, with independent Gaussian noise of SD 2. The sparse setting has coefficients (2, −1.5, 1, 0, …, 0); the dense setting has twenty nonzero, alternating-sign coefficients of magnitudes 0.45–0.85. Training, validation and test observations are generated independently from the same model. The seed makes each simulation reproducible.

OLS and ridge are solved by pivoted elimination; LASSO uses coordinate descent with soft thresholding. Objectives use RSS/(2n) + (λ/2)||β||22 for ridge and RSS/(2n) + λ||β||1 for LASSO on standardized predictors. A common grid of λ = 0 and 49 positive log-spaced values from 10−4 to 10 is evaluated separately for each penalty. Coefficients in the plot are converted back to the original feature scale.
